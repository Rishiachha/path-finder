# Path Finder

Build a complete responsive React website page called:
"Discover Your Path"
for:
"Rishi Sidhasamdhi Yoga Foundation"
================================================
CORE VISION
Create an immersive personal journey page where visitors discover yoga and meditation practices based on their current needs and intentions.
This page is NOT a knowledge article.
This page is NOT a blog.
This page is NOT a normal card grid.
The feeling should be:
- Ancient wisdom guiding a modern person
- Personal transformation journey
- Spiritual path finder
- Cinematic storytelling
- Peaceful self-discovery experience
The user should feel:
"I have arrived at the right place for my current journey."
================================================
CONCEPT
The page answers:
"Where are you today?"
and guides the user towards:
"Which practice can support you?"
The journey flow:
Hero
↓
Choose Your Intention
↓
Discover Your Path
↓
Recommended Practices
↓
Begin Your Journey
================================================
DESIGN STYLE
Match the visual identity of Rishi Sidhasamdhi Yoga Foundation.
Use:
- Warm ivory background
- Deep forest green
- Soft gold accents
- Elegant serif typography
- Large nature imagery
- Slow animations
- Spacious layouts
Avoid:
- SaaS design
- Dashboard UI
- Bright colors
- Excessive cards
- App-like interfaces
- Generic wellness website style
================================================
